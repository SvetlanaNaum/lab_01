# Лабораторная работа №1

## Описание

Консольное приложение на Python, состоящее из калькулятора и конвертера величин.

Проект реализует:
- вычисление арифметических выражений;
- конвертацию единиц длины, массы и температуры;
- обработку ошибок;
- автоматическое тестирование;
- запуск через командную строку.

## Калькулятор

Калькулятор поддерживает:

- `+` — сложение;
- `-` — вычитание;
- `*` — умножение;
- `/` — деление;
- `//` — целочисленное деление;
- `%` — остаток от деления;
- `**` — возведение в степень;
- унарные `+` и `-`;
- круглые скобки;
- целые и дробные числа;
- приоритет арифметических операций.

Для вычисления выражений не используются `eval`, `exec` и готовые парсеры выражений.

## Конвертер

Поддерживаются следующие единицы измерения.

### Длина

- `mm` — миллиметры;
- `cm` — сантиметры;
- `m` — метры;
- `km` — километры.

### Масса

- `g` — граммы;
- `kg` — килограммы.

### Температура

- `c` — градусы Цельсия;
- `f` — градусы Фаренгейта;
- `k` — Кельвины.

Регистр единиц измерения не имеет значения.
